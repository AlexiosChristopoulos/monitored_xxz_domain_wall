\section*{Scope and provenance}
Ninth item in the ordered project queue. This focused Julia MPS package
studies a finite XXZ domain wall under periodic local projective $Z$
measurements. It includes source, dependency metadata, README, example,
tests, benchmark, model note, and an executed Jupyter notebook. The
motivation is Gunawardana, Moghaddam, and Ojanen,
\textit{Postselection-free ballistic-diffusive transition in monitored spin
chains}, arXiv:2605.27350 (2026). No paper figure or code was copied.
The local \texttt{noisy\_transverse\_ising} finite-step trajectory pattern
was adapted. No connected GitHub source was reused; the dependencies retain
their upstream licenses. \texttt{boundary\_xxz\_reference} was untouched.

The zero-monitoring four-site trajectory at $t=0.4$ differed from exact
dense unitary magnetizations by at most $1.5271\times10^{-4}$ for period

periods. The exact dense channel retained unit trace and a nonnegative
spectrum to numerical tolerance. For $N=4$, $J=0.7$, $\Delta=0.35$,
$p=0.4$, period $0.1$, and five periods, the exact right-half transfer was
$0.15066089$; 700 MPS trajectories gave $0.13256506\pm0.01180447$
(one estimated standard error). The maximum magnetization difference was
$0.03303403$; all sampled components passed the four-standard-error plus
$0.025$ finite-step allowance in the test. The final total magnetization
was zero to machine precision in both calculations.

The warmed illustrative benchmark for 100 trajectories over five periods
took 1.251 s at $N=6$ (largest bond 7) and 2.501 s at $N=10$
(largest bond 8). This is a local timing, not a scaling estimate. Three
Julia code cells in the notebook were executed sequentially and their
printed outputs saved. No commit, push, publication, release, or GitHub
repository modification was performed.
\section*{Limits}
The MPS calculation has finite-period symmetric-split error, bond
truncation, and Monte Carlo uncertainty. The exact baseline is capped at
four spins. Varying period at fixed measurement probability changes the
physical monitoring rate. No ballistic-diffusive or entanglement-transition
claim is supported by these small finite chains.
